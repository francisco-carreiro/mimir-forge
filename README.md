# ⚔️ MÍMIR FORGE

**Windows intelligence, diagnostics and reversible configuration.**

MÍMIR FORGE is a Windows 11 desktop utility with Norse-inspired visuals.

## Download

Windows executables will be published in [Releases](https://github.com/francisco-carreiro/mimir-forge/releases) after Windows build and safety validation. **No official executable has been published yet.**

The distributed app will include diagnostics and opt-in configuration controls. Read each proposed change and create a verified System Restore point before modifications.

> Early development preview. Evaluate it in a Windows 11 VM before using repair features on important machines.

## Privacy

Local-first, no MÍMIR telemetry. Some optional Windows tools contact Microsoft or external package sources.

## Distribution

This **public** repository contains product documentation and, eventually, downloadable release binaries. Development source code is kept in a separate private repository.

A SHA-256 checksum will accompany every published executable. A Windows executable may still be reverse engineered; code signing and independent verification are recommended.
