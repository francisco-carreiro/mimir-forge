# ⚔️ MÍMIR FORGE

### Know your system. Master your machine.

**Windows 11 Intelligence • Diagnostics • Safe Configuration • Recovery**

MÍMIR FORGE brings system inspection, practical Windows preferences and guided maintenance together in a desktop application inspired by Norse mythology. Explore your machine through the Nine Realms: an iron-dark interface with crimson highlights, antique-gold details and a Yggdrasil-inspired emblem.

## Personalize Windows your way

MÍMIR FORGE includes **17 opt-in Windows configuration preferences** covering:

- **File Explorer:** file extensions, hidden items, selection checkboxes, open-to-This-PC, compact layout, thumbnails, status bar and navigation pane behavior.
- **Taskbar:** alignment, Task View, Widgets and clock seconds.
- **Start:** recent-document tracking and available recommendation preferences.
- **Classic context menu:** an optional, experimental Windows 11 compatibility setting for the older right-click menu.

Each setting is selected individually. The app displays what will change before requesting approval. Some preferences depend on the Windows build; the classic context-menu override may affect modern Explorer extensions. **Changing these preferences is personalization, not a guaranteed performance improvement.** MÍMIR FORGE does not claim to restore older Windows 11 Start layouts through unsupported tricks.

## Safety before speed

**Your choices remain in your hands.**

- **Read-only first:** scans run only when selected; no automatic system changes at startup.
- **Permission-based changes:** proposed modifications are reviewed and explicitly approved.
- **Restore-point protection:** MÍMIR requests and verifies a new Windows restore point before its system-changing operations. If protection cannot be verified, the operation is blocked.
- **Reversible preferences:** eligible registry changes keep a local history for review and undo.
- **Visible execution:** diagnostic output and errors appear inside MÍMIR rather than launching separate command windows.
- **Windows security respected:** no automatic disabling of Defender, firewall, Windows Update, Secure Boot or memory integrity.

Windows UAC prompts may still appear for administrator tools. **System Restore is not a replacement for full backups**, and Windows repair operations may not be completely reversible.

## Everything in one place

**42 built-in Windows inspection and maintenance tools** across diagnostics, security, repairs, software and gaming, plus **17 individually selectable configuration preferences**.

MÍMIR combines practical tools into one consistent interface. These are not 59 “performance boosts”: many features are inspections, repair utilities or personal preferences.

## Privacy and control

MÍMIR is **local-first**, with no built-in MÍMIR account, telemetry or analytics. Some user-initiated tools, including software update discovery and Windows repair sources, may connect to external services. Diagnostic output and exported reports can include local machine details, so review them before sharing.
